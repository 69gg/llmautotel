# LLMAutoTel

可配置的电话咨询与语音工作台。用户来电后，AI 简短欢迎，再根据产品资料与提示词介绍功能、回答问题。原有销售外呼和浏览器语音完整保留，按配置切换；四种电话 provider 的总开关和接听开关全部默认关闭。

## 本机启动

需要 uv、Python 3.12、Node.js 和 pnpm。依赖分别由 `uv.lock` 和 `frontend/pnpm-lock.yaml` 锁定，Python 版本由 `.python-version` 指定。

```sh
uv sync --locked
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
uv run llmautotel
```

打开 `http://127.0.0.1:8765`。默认只监听本机，语音需要浏览器的本机或 HTTPS 安全上下文。

## 使用

1. 进入“对话配置”，选择默认的产品咨询，填写产品资料和回复要求。固定开场白可留空，由 AI 生成简短欢迎。选择销售模式可使用原有销售目标、资料和话术；两组内容独立保存，切换不会删除。
2. 分别填写 ASR、文本 LLM 和 TTS 的 API 根地址与模型名；TTS 还需音色。密钥只在需要鉴权时填写，三个服务可以属于不同供应商。
3. 保存配置，回到“语音通话”点击开始并允许麦克风访问。连接就绪后 AI 先说话；你开口时会打断它，停止说话后根据新发言回应。换问题后直接回答当前问题，明确要求继续时才接回旧话题。
4. 用静音按钮暂停发送麦克风声音，挂断结束通话。咨询模式按资料答疑，不主动推销或挽留；仅在明确要求结束或明确表示咨询结束时礼貌告别。销售模式保留首次购买拒绝挽留一次、再次拒绝或直接要求结束时告别挂断。告别带祝福，播放结束后才挂断；原生语音告别期间再次开口会取消待执行挂断。云平台播放确认范围见相应接入文档。切换页面不会挂断；通话期间保存的配置用于下一通。
5. 在“通话记录”查看文字、时间、目标、结束原因和当时的配置快照。被打断的输出有“播放未完成”标记，已结束记录可删除。

同时只允许一通会话，两标签页同时开始时第二个会收到占用提示。麦克风授权被拒绝时先在浏览器中允许本机站点访问，再重新开始。模型或连接失败会结束本通，页面显示失败阶段，修正配置后可重新开始。

咨询模式直接回答最新问题，依据产品资料介绍功能、使用方法或价格；资料没有的事实明确说明无法确认。只澄清回答当前问题所必需的信息，不调查用户用途，也不承诺没有工具支持的业务操作。销售模式采用通用的直接推销规则：先回答当前问题，再介绍一项资料支持的价值，最后围绕配置的购买、订阅、预约演示等目标询问意向。不调查用途、使用场景、频率或职业；用户主动提供的信息可以用于介绍相关价值。程序不预设具体产品，拒绝后的唯一一次挽留也采用这种表达。

音量反馈来自实际音轨。浏览器阻止自动播放时点击“播放声音”。首次调试建议使用耳机；外放回声和环境噪声可能导致 VAD 误判，真实设备效果需另行验收。

## 模型兼容范围

| 服务 | 接口 | 格式 |
| --- | --- | --- |
| ASR | `/audio/transcriptions` | WAV multipart，JSON `text`，默认识别语言 `zh` |
| 文本 LLM | `/chat/completions` | 标准流式 SSE 文本 |
| TTS | `/audio/speech` | 原始单声道、16 位小端 PCM，默认采样率 24 kHz |

地址填写接口根路径，应用会追加对应接口路径。TTS 音色允许服务商自定义名称，采样率必须与服务实际输出一致；WAV、MP3、Opus 不在第一版 TTS 兼容范围。未预填真实服务商、模型或密钥。详细请求与鉴权规则见 [模型接入文档](docs/providers.md)。
小米 MiMo 可在 ASR / TTS 中分别选择“小米 MiMo”协议，使用 `/chat/completions` 传输 WAV Base64 和流式 PCM 音频。文本 LLM 支持可选思考模式和推理强度，不发送 token 上限。MiMo 与 DeepSeek 的具体配置见 [接入说明](docs/model-setup.md)。

## 电话接听与外呼

工作台默认打开“电话接入”的来电监控。优先使用已开通的企业 SIP／VoIP 线路或云平台原生来电智能体；浏览器仅显示状态和文字，语音通过电话线路传输。

1. 完成咨询资料与所需模型配置。
2. 选择 provider，填写入呼参数，打开总开关和“启用来电接听”后保存。Asterisk／FreeSWITCH 会后台建立来电事件连接；阿里／腾讯等待云平台的认证路由回调。保存不会外呼。
3. 将甲方号码路由到 PBX 专属入呼应用，或云平台的来电智能体与本机认证网关。云路由需要应用号、号码白名单和独立认证参数，不能把外呼 API 当作接听 API 使用。
4. 接通且媒体就绪后，AI 简短欢迎并答疑。用户挂断或明确结束时收尾，保存文字、号码、方向、模式与配置快照。同一时间只接受一通，其他来电忙线拒接。

首次升级会保留完整销售配置，将旧产品资料复制到独立咨询资料并默认选咨询；旧推销要求和销售开场不自动带入咨询。已有文字历史保持原样。

| 优先入呼方案 | 实际接入 |
| --- | --- |
| 企业 SIP／VoIP 线路 | Asterisk 专属 Stasis 入呼＋ARI＋双向 PCM WebSocket，或 FreeSWITCH 专属 park 入呼＋ESL＋UDP PCM |
| 阿里云 | AICCS 通信智能引擎的大模型应用呼入号码绑定、开场变量回调＋本机 LLM 网关 |
| 腾讯云客服 TCCC | 正式 `callInBound` 动态路由、预配置来电 AI 智能体＋本机 LLM 网关 |

阿里 AICCS 的适配不等同于所有阿里 CCC 产品通用；甲方合同提供标准 SIP 中继时，也可选原生 SIP 方案。容联、智齿、百应等服务若提供标准 SIP 线路，可经同一 PBX 复用；没有已确认公开协议的专有接口不作占位适配。步骤、回调和边界见 [来电接入](docs/telephony-inbound.md)。

原有外呼在电话页切换到外呼使用：选择已启用的 provider 并填写被叫号码，点击“发起外呼”才创建电话。选择销售模式可启用旧版推销行为；方向与对话模式是独立配置。PBX／云账号与线路应先由甲方开通，应用不自动注册中继或配置硬件。

| Provider | 语音模型 | 接入准备 |
| --- | --- | --- |
| Asterisk | 本机已配置 ASR／LLM／TTS | [ARI＋双向 PCM WebSocket](docs/telephony-asterisk.md) |
| FreeSWITCH | 本机已配置 ASR／LLM／TTS | [ESL＋原生双向 UDP PCM](docs/telephony-freeswitch.md) |
| 阿里云 AICCS | 平台 ASR／TTS，本机 LLM 网关 | [LlmSmartCall 与 MSML](docs/telephony-cloud.md) |
| 腾讯云 TCCC | 平台 ASR／TTS，本机 LLM 网关 | [CreateAICall 与自有模型接口](docs/telephony-cloud.md) |

运营商 SIP 中继、FXO、E1/PRI 和 VoLTE SIM 语音网关，通过 Asterisk 或 FreeSWITCH 的 SIP 路由复用同一 provider，无需针对硬件品牌改应用代码。接口边界与未纳入方案见 [电话接入总览](docs/telephony.md)。被叫号码接受 7–15 位数字及可选开头加号，号码与中继路由由甲方决定。

来电、外呼和网页语音共用单会话限制及每通配置快照。电话页提供状态、文字、手动挂断和历史；不使用浏览器麦克风，离开页面不挂断。原生媒体就绪后才欢迎或按销售配置开场，并复用最新发言优先、打断和告别播放完成后挂断。云托管模式的打断、播放和结束由平台执行；文字从正式回执／官方交互记录导入，不把生成稿冒充已经说过。

云平台需要可访问的 HTTPS 模型网关和电话回执地址。公网反向代理只开放文档列出的这几个认证入口；本机配置、历史和外呼管理接口留在管理网。详细地址、鉴权、平台准备步骤及播放确认限制见各 provider 文档。实际线路与云应用尚未接通验收，协议测试不代表真实手机播放效果已验证。

## 数据与通话记录

SQLite 默认保存在 `data/app.sqlite3`，目录权限 `0700`、文件权限 `0600`，已排除出 Git。配置中的密钥保存在服务端，配置回读只返回是否已设置；网页不把密钥写入持久存储。留空密钥输入表示保留原值，点击清除则删除已有密钥。

历史仅保存文字、时间、结束原因及脱敏配置快照，不保存录音、临时音频或密钥。已说内容按句提交：完整输出的句子保留，打断时的半句不作为已经说过的内容，可能留下正文为空的中断记录。打断前已生成但未完整播放的文字另以带状态标签的背景加入本通上下文，用于理解“这个”“人民币多少钱”等后续发言，不自动续播，也不视为用户已听到。首版不提供逐字播放时间对齐。

生成背景以内部系统消息保留，不伪装成 AI 已经说过的话。背景标签和管理说明不属于对话正文；语音合成之前使用 Pipecat 的流式模式匹配过滤，避免模型复述标记时进入声音、网页文字或下一轮草稿。正常产品正文和普通括号保留，未闭合的内部标记在生成结束或打断时丢弃。

打断后没有 AI 生成文字可作背景时，连续的用户发言在模型请求中明确分为历史背景与当前问题，避免模型先补答旧问题。原始用户发言和文字记录保持完整；完整助手回复及内部系统背景按原顺序保留。

网页语音中，用户挂断或断连会取消模型任务、停止音频并释放连接和麦克风。AI 挂断等待告别音频完成，再优雅结束；记录原因为 `ai_hangup`，历史页显示“AI 确认结束”。网页语音连接未完成的预留会话默认 30 秒后释放；电话按各 provider 的拨号、媒体或回执超时收尾，播放确认范围见对应接入文档。正常退出保存 `server_shutdown` 原因；进程意外终止后重启，将未结束记录标记为 `server_restarted`。删除记录不可通过应用恢复。

本阶段面向本机单用户，未提供账号系统；默认保持本机监听，所有电话连接默认关闭。浏览器连接本机后端，后端按配置访问模型服务。显式开启接听后维护原生事件连接，或认证处理云平台路由；只有手动发起外呼才调用拨号接口。没有支付或知识库，首次安装依赖需访问包仓库。

## 开发环境

后端使用上面的启动命令，前端开发另开终端：

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

前端开发服务器代理 `/api` 到本机后端。后端环境变量见 [.env.example](.env.example)，程序不自动加载该文件。可通过 `LLMAUTOTEL_HOST`、`LLMAUTOTEL_PORT`、`LLMAUTOTEL_DATA_DIR` 和 `LLMAUTOTEL_CONNECTION_TIMEOUT_SECONDS` 调整运行配置。前端代理与 REST 超时见 [前端说明](frontend/README.md)。模型参数在网页填写。

语音业务位于 `src/llmautotel/voice.py`，生成背景保留位于 `conversation.py`，内部标记过滤位于 `speech.py`，挽留与挂断工具位于 `hangup.py`，连接和会话管理位于 `sessions.py`，三个模型协议适配位于 `providers.py`，电话 provider 和模型网关位于 `telephony/`。升级 Pipecat 前需核对锁定版本的句级音频和回合结束钩子；原因见 [语音管线文档](docs/voice.md)。
