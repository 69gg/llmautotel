# LLMAutoTel

本机网页语音销售助手。配置销售目标、产品资料、话术和独立的 ASR、文本 LLM、TTS 服务，通过浏览器与 AI 对话。

## 本机启动

需要 uv、Python 3.12、Node.js 和 pnpm。依赖分别由 `uv.lock` 和 `frontend/pnpm-lock.yaml` 锁定，Python 版本由 `.python-version` 指定。

```sh
uv sync --locked
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
uv run llmautotel
```

打开 `http://127.0.0.1:8765`。默认只监听本机，语音需要浏览器的本机或 HTTPS 安全上下文。

## 使用

1. 进入“对话配置”，填写销售目标、产品资料和话术要求。固定开场白可留空，由 AI 根据配置生成简短开场。
2. 分别填写 ASR、文本 LLM 和 TTS 的 API 根地址与模型名；TTS 还需音色。密钥只在需要鉴权时填写，三个服务可以属于不同供应商。
3. 保存配置，回到“语音通话”点击开始并允许麦克风访问。连接就绪后 AI 先说话；你开口时会打断它，停止说话后根据新发言回应。换问题后直接回答当前问题，明确要求继续时才接回旧话题。
4. 用静音按钮暂停发送麦克风声音，挂断结束通话。首次明确表示“不需要／不买了／不用了，谢谢”时，AI 温和挽留一次，再次明确拒绝后完整说完带祝福的回复（如“祝您生活愉快，再见”）后结束。直接说“挂了吧／别再打扰／结束通话”会直接告别挂断。含糊时继续对话，不询问是否挂断。挽留被打断也不重复，告别期间再次开口会取消待执行的挂断。切换页面不会挂断；通话期间保存的配置用于下一通。
5. 在“通话记录”查看文字、时间、目标、结束原因和当时的配置快照。被打断的输出有“播放未完成”标记，已结束记录可删除。

同时只允许一通会话，两标签页同时开始时第二个会收到占用提示。麦克风授权被拒绝时先在浏览器中允许本机站点访问，再重新开始。模型或连接失败会结束本通，页面显示失败阶段，修正配置后可重新开始。

话术采用通用的直接推销规则：先回答当前问题，再介绍一项资料支持的价值，最后围绕所配置的目标询问意向。购买、订阅、预约演示等目标使用同一套规则，不调查用途、使用场景、频率或职业；用户主动提供的信息可以用于介绍相关价值。目标与产品事实来自配置，程序不预设具体产品。只询问意向，未提供实际操作工具时不承诺代客开通、下单或预约。拒绝后的唯一一次挽留也采用这种表达。

音量反馈来自实际音轨。浏览器阻止自动播放时点击“播放声音”。首次调试建议使用耳机；外放回声和环境噪声可能导致 VAD 误判，真实设备效果需另行验收。

## 模型兼容范围

| 服务 | 接口 | 格式 |
| --- | --- | --- |
| ASR | `/audio/transcriptions` | WAV multipart，JSON `text`，默认识别语言 `zh` |
| 文本 LLM | `/chat/completions` | 标准流式 SSE 文本 |
| TTS | `/audio/speech` | 原始单声道、16 位小端 PCM，默认采样率 24 kHz |

地址填写接口根路径，应用会追加对应接口路径。TTS 音色允许服务商自定义名称，采样率必须与服务实际输出一致；WAV、MP3、Opus 不在第一版 TTS 兼容范围。未预填真实服务商、模型或密钥。详细请求与鉴权规则见 [模型接入文档](docs/providers.md)。
小米 MiMo 可在 ASR / TTS 中分别选择“小米 MiMo”协议，使用 `/chat/completions` 传输 WAV Base64 和流式 PCM 音频。文本 LLM 支持可选思考模式和推理强度，不发送 token 上限。MiMo 与 DeepSeek 的具体配置见 [接入说明](docs/model-setup.md)。

## 数据与通话记录

SQLite 默认保存在 `data/app.sqlite3`，目录权限 `0700`、文件权限 `0600`，已排除出 Git。配置中的密钥保存在服务端，配置回读只返回是否已设置；网页不把密钥写入持久存储。留空密钥输入表示保留原值，点击清除则删除已有密钥。

历史仅保存文字、时间、结束原因及脱敏配置快照，不保存录音、临时音频或密钥。已说内容按句提交：完整输出的句子保留，打断时的半句不作为已经说过的内容，可能留下正文为空的中断记录。打断前已生成但未完整播放的文字另以带状态标签的背景加入本通上下文，用于理解“这个”“人民币多少钱”等后续发言，不自动续播，也不视为用户已听到。首版不提供逐字播放时间对齐。

生成背景以内部系统消息保留，不伪装成 AI 已经说过的话。背景标签和管理说明不属于对话正文；语音合成之前使用 Pipecat 的流式模式匹配过滤，避免模型复述标记时进入声音、网页文字或下一轮草稿。正常产品正文和普通括号保留，未闭合的内部标记在生成结束或打断时丢弃。

打断后没有 AI 生成文字可作背景时，连续的用户发言在模型请求中明确分为历史背景与当前问题，避免模型先补答旧问题。原始用户发言和文字记录保持完整；完整助手回复及内部系统背景按原顺序保留。

用户挂断或断连会取消模型任务、停止音频并释放连接和麦克风。AI 挂断等待告别音频完成，再优雅结束；记录原因为 `ai_hangup`，历史页显示“AI 确认结束”。连接未完成的预留会话默认 30 秒后释放。正常退出保存 `server_shutdown` 原因；进程意外终止后重启，将未结束记录标记为 `server_restarted`。删除记录不可通过应用恢复。

本阶段面向本机单用户，未提供账号系统；默认保持本机监听。没有电话线路、支付、知识库或外部音视频平台。浏览器运行时连接本机后端，后端按配置访问三个模型服务；首次安装依赖需访问包仓库。

## 开发环境

后端使用上面的启动命令，前端开发另开终端：

```sh
cd frontend
pnpm install --frozen-lockfile
pnpm dev
```

前端开发服务器代理 `/api` 到本机后端。后端环境变量见 [.env.example](.env.example)，程序不自动加载该文件。可通过 `LLMAUTOTEL_HOST`、`LLMAUTOTEL_PORT`、`LLMAUTOTEL_DATA_DIR` 和 `LLMAUTOTEL_CONNECTION_TIMEOUT_SECONDS` 调整运行配置。前端代理与 REST 超时见 [前端说明](frontend/README.md)。模型参数在网页填写。

语音业务位于 `src/llmautotel/voice.py`，生成背景保留位于 `conversation.py`，内部标记过滤位于 `speech.py`，挽留与挂断工具位于 `hangup.py`，连接和会话管理位于 `sessions.py`，三个模型协议适配位于 `providers.py`。升级 Pipecat 前需核对锁定版本的句级音频和回合结束钩子；原因见 [语音管线文档](docs/voice.md)。
