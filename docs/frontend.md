# 工作台操作

工作台默认打开“电话接入”的“来电接听”视图，展示四组 provider 的接听状态和当前通话。未启用的线路不建立连接；页面查询状态不会拨号，也不调用浏览器麦克风。

先在“对话配置”选择产品咨询，填写准确的产品资料、可选咨询提示词和欢迎语，再配置模型。咨询模式无需销售目标；欢迎语为空时，接通后生成一句简短欢迎，用户已先发言则直接答疑。“销售推介”保留原来的目标、资料、话术和开场，切换模式不会删除任何一组配置。正在通话使用开始时的快照，保存新资料仅影响下一通。

在电话页面下方选择 provider，填写服务端目录所描述的连接参数。“启用此 provider”和“启用来电接听”都开启并保存后，本机 SIP 媒体方案会在后台建立监听。关闭接听不会中断已开始的通话；使用通话区域的“挂断电话”结束当前会话。云平台还需按接入文档配置号码路由、模型网关及正式回调。云方案的接听号码白名单必填，本机专属路由可留空；多个号码支持逗号或换行分隔。连接凭据保存后不回显，不写浏览器持久存储。

“正在监听”表示本机媒体监听连接已建立。“等待来电回调”表示云 provider 的本机配置已就绪，不能由此判断云号码路由、运营商线路或账户健康。“配置未完成”“连接失败”和具体安全错误帮助定位未就绪的阶段。页面每秒读取状态，切换页面后停止查询，电话继续由服务端管理。

“手动外呼”切换保留原来的号码输入和发起按钮，仅手动点击发起才外呼。外呼与来电、浏览器语音共用一通会话槽。来电展示主叫与接听号码、咨询或销售模式以及文字；云托管文字在正式回执或官方交互记录到达后显示。

“语音通话”入口继续提供浏览器测试，可在电话线路开通前验证咨询或销售话术。“通话记录”展示方向、provider、号码和配置快照；旧记录没有模式或方向时，沿用销售和外呼显示，避免把历史记录改写成来电咨询。

自动化测试检查默认入口只读、模式切换保留、元数据布尔/数组字段、接听开关与号码提交、来电轮询与切页清理、挂断共享接口、咨询历史和旧记录兼容。TypeScript/Vite 构建检查生产入口；真实云路由和电话设备结果需另行验收。

线路步骤见 [电话接入总览](telephony.md)，对话与播放规则见 [语音管线](voice.md)。
