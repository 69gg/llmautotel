使用本机 Chromium 内嵌浏览器查看实际生产构建，完成 1280 × 900 桌面通话页、配置页和历史空状态检查，以及 390 × 844 窄屏布局检查。服务端未填真实供应商和模型参数时，开始按钮禁用并提供前往配置操作；这次浏览器检查没有保存模型配置或输入密钥。

生产页面加载的网络请求已观测为本机 HTML、JS、CSS 与 `/api/settings`。客户端通过官方 MediaManager 扩展接口使用原生麦克风适配器，不实例化默认 Daily 设备管理器；没有外部字体、设备脚本或默认 STUN/TURN 配置。这次页面检查没有发起真实模型请求或获取真实麦克风，因此不将其计为实际语音体验。

通话、配置、历史页面导航与本机数据读取正常。窄屏配置页没有横向溢出，图标导航保留“语音通话 / 对话配置 / 通话记录”可访问名称；临时视口覆盖已恢复。历史文字与删除交互在前端自动化中验证，浏览器检查使用本机空历史，未删除用户数据。
